Appli de relevé des pathologies d'audit énergétique (Diag Pro Eco).
Adresse : https://diagproeco.github.io/pathologies/

Les visites et les photos sont gardées dans le téléphone. Une fois l'envoi direct activé sur le téléphone
(lien d'activation), elles partent toutes seules dans le Google Drive de Diagproeco, dossier « Pathologies audit »,
par un script Google privé protégé par une clé. L'adresse du script et la clé restent dans le téléphone :
rien n'est stocké ici.
